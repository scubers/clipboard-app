# ClipboardTool (Xcode project)

This folder contains an **Xcode project** generated by **XcodeGen**.

## Why
SwiftPM is great for development, but a real `.app` project makes it easier to:
- Archive/Export
- Configure signing / entitlements
- Implement Launch at Login

## Requirements
- Xcode
- XcodeGen (`brew install xcodegen`)

## Generate / Regenerate
From repo root:

```bash
cd macos/Xcode
xcodegen generate
```

## Build
From repo root:

```bash
xcodebuild -project macos/Xcode/ClipboardTool.xcodeproj \
  -scheme ClipboardTool \
  -configuration Debug \
  -destination 'platform=macOS,arch=arm64' \
  build
```

## Notes
- The project runs a pre-build script to build the Go core dylib.
- The project embeds `libclipboardtool.dylib` into `Contents/Resources/`.
- Code signing is disabled for Debug builds (can be enabled when distributing).
